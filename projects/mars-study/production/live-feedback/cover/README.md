# Before the crash

The selected cover shows the delivered habitat inflated, intact and unpowered, before the spacecraft arrives. Start opens the existing “coming in hot” introduction, then the crash scene shows the collapsed habitat and landed module.

`request.json` retains the exact built-in imagegen request. `reference.png` is its necessary input: the original crash landscape with the inflated habitat fitted. `before-crash.png` is the selected generated master. `export-cover.py` resizes the whole frame to 780 × 1688 using Lanczos and writes a lossless opaque WebP without cropping or recolouring.
