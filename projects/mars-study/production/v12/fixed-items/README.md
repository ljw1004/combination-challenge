# Mars v12 fixed-item production

This is the current production path for [Mars v12](../../../mars-v12/mars.md). It replaces the first illustrated pass's movable buildings and detached scene crops. The [design brief](../../../mars-v12/design-brief.md) owns physical and narrative intent; the [icon guide](../../../../../docs/icon-guide.md) owns reusable graphics methods.

## Source of truth

- `source-mars.md` is the retained manuscript before this migration. `tools/rewrite-manuscript.py` applies the selected interaction and prose changes, declares identities, writes chapter-local fixed views and `from chapter` appearances, and produces `manuscript-manifest.json`. Edit the migration when changing its generated manuscript.
- `scene-layout.json`, generated by `tools/prepare-layout.py`, selects the current full-scene masters and their state cells, crop canvases, initial background, fixed coordinates and compound fittings. `tools/trace-layout.py` contains the authored extraction outlines and holes. These paths retain existing painted pixels; they do not synthesize new artwork.
- `sources/` contains the selected imagegen masters used by the exports. `prompts/` preserves their exact executed requests and original reference paths; superseded inputs and temporary reference crops are no longer retained. Selected shelter-free scenes have `open-ground` in their names. `34-interior-specimen-stow` replaces exterior sample loading. `13-fragmented-membrane`, `item-cabin-mattress-r3` and `item-tool-kit-symbol` carry the latest discovery, bedding and stock-symbol corrections.
- The chapter 18 microscope painting is kept only in [the playable asset directory](../../../mars-v12/assets/fixed/discoveries/intact-body-in-ice.png), with its [generation request](prompts/18-intact-body-view.json) here. Its duplicate source PNG had identical pixels and has been removed.
- `registration.json` records source cell bounds, alignment transforms, extraction bounds, pixel dimensions, masks and placement centres together. `artwork.json` is the resulting manuscript metadata; do not hand-edit it.
- `portable-requests.json` and `portable-exports.json` select and record movable depictions. `artwork-extra.json` supplies those icons and global chapter appearances. Steel and Tool kit display at 44 reference pixels across.

## Export method

Generate the complete scene and its changing states together, register them against the common setting, then extract the fixed artwork. Stable painted features receive fully transparent hit-area PNGs. Changing objects use traced transparency where possible; opaque replacement areas remain when necessary to erase an earlier state. Independent additions must not repaint another independently changing object. Every state family keeps a common canvas and physical scale.

Backgrounds are 780 × 1688; fixed PNGs are four times their reference display dimensions. They must retain that scale in the browser, including images wider than the movable-icon cap. The background and fixed artwork share the same viewport transform. Hotspot declaration order supplies their back-to-front order. Compound overlays have the base canvas's exact dimensions.

`export-scenes.py` retains the scene's object proportions, extending only the quiet foreground with a colour-matched join. This is compositing of generated source pixels. All new painting and content edits used the built-in image-generation tool.

## Reproduce

From the repository root, with Pillow, NumPy and OpenCV installed in an ignored virtual environment:

```sh
python3 projects/mars-study/production/v12/fixed-items/tools/prepare-layout.py
runs/mars-v12-fixed/.venv/bin/python projects/mars-study/production/v12/fixed-items/tools/export-portables.py
runs/mars-v12-fixed/.venv/bin/python projects/mars-study/production/v12/fixed-items/tools/export-scenes.py
python3 projects/mars-study/production/v12/fixed-items/tools/rewrite-manuscript.py
```

Wait for each export to finish before rewriting the manuscript. Numeric arguments to `export-scenes.py` restrict an image-only repair to those chapters while preserving other exported metadata. For new identities, first update the migration's declarations and manifest, then export and rewrite; stale artwork belonging to explicitly removed identities is ignored during that preparatory rewrite. The original `production/v12/tools/integrate-artwork.mjs` is for the pre-migration pass and must not be run over this manuscript.

Inspect the manuscript in `/combinations.html?story=projects/mars-study/mars-v12/mars.md`. A browser-saved editor draft can shadow the on-disk file; use the game's existing draft controls when comparing versions.
