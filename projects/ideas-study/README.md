# Ideas study

Continuing development of [History of ideas](../../stories/ideas/ideas.md), guided by the game's [educational purpose](../../README.md#philosophy) and the story's [design brief](../../stories/ideas/design-brief.md). The current revision keeps the ancient-to-modern threads while selecting encounters for important connections or discoveries worth experiencing in their own right.

Playtests follow the shared [evaluation method](../../docs/fun-and-evaluation.md#chapter-fun-playtests). Retained runs contain accepted player responses, independent assessments, chapter syntheses and the mechanically assembled report. These are local chapter assessments, not continuous whole-story player journeys, browser tests, human enjoyment measurements or factual authenticity reviews.

## Shorter journey

The current manuscript has **57 playable chapters**, down from 85, and a **164-combination completion route**, down from 272. Source length is 67.7% of the baseline; automatic route prose is 72.8%. Counts describe structure and text, not human duration. Repeated preparations and conclusions have been folded; selected calculations, observations, interpretations and institutional cases now carry explicit evidence and consequences. Desk clearing stays implicit.

The [working notes](working-notes.md) record selection decisions, every chapter's scores, strongest/weakest patterns, independent source-review findings, successive changes and remaining questions. Verification follows the user's request to work entirely in logical game space.

## Evaluation runs

Each run uses `--fast`, three fresh Terra Medium players per chapter, one fresh Astra High grader per record, and a separate fresh Astra High chapter synthesizer. The same educational guidance is supplied throughout. The goal-free ending has no separate chapter assignment. Fun is not measured.
