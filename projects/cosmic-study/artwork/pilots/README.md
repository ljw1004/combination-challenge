# Retained style comparison

The [80 px three-style sheet](comparison-80px.png) is a deliberate design reference: the same twelve physical subjects make it useful for comparing broad colour, negative space and stellar-point clarity without retaining the whole trial set. View at 100% zoom. Labels A1–A12, B1–B12 and C1–C12 identify the same ordered subjects in [pilot-prompts.json](../pilot-prompts.json); A is luminous pastel, B flat screenprint and C observatory engraving.

This is a historical comparison, not the selected production inventory. The chosen direction is luminous pastel with targeted physical repairs and open fixed receivers; the [artwork overview](../README.md) links the current 179 assets and accepted outcomes. The sheet preserves useful alternatives even though B and many individual pilot cells were rejected. [Compact provenance](comparison-80px.json) records source hashes, cell order, unchanged extraction geometry, image bounds and the sheet hash.

The redundant 36 trial exports, 64/96 px sheets and trial extraction manifests were removed. The A master remains in production; the C original remains because it was an actual reference input for the selected outskirts receiver. B's unselected source was removed from the project. Original generation-cache files were left intact. Use the [production manifest and tools](../tools/README.md) for future extraction.
