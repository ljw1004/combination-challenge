# Independent evidence restoration

`evidence-bundle.tar.gz` is lossless gzip/tar of original repository-relative evidence, reviewer scripts and review. `evidence-inventory.json` records each member's original path, exact byte count and SHA-256. No summaries replace raw captures. Extract into an empty directory (not over an active working tree), then verify every member against that inventory. Campaign capture files already ending `.gz` are separately lossless compressed original JSON; their nearby manifests supply original hashes/bytes.

For historical reproduction, create a separate scratch checkout containing the selected snapshot's files at their original paths: `results/geometric-materials-independent/freeze-v1/` for initial source, or `final-v2/` for repaired source. Do not overwrite live/old evidence. Copy reviewer scripts into its `experiments/`. Use Node with TypeScript support (audit used Node 24.22.1). Initial `independent-probes.ts` and `independent-joint.ts` deliberately assert the preserved failures; repaired equivalents assert fixes. The repaired-probes script takes NEW output-directory and exact freeze-path arguments. Campaign and CLI scripts also accept output directory and freeze path. Reconstruct the corresponding `results/geometric-materials-preplay/{freeze-v1,final-v2}/source-freeze.json` from the preserved snapshot manifest. Ensure selected source hashes match before running. CLI harness copies its own temporary workspace under its new output directory.

Initial sources and repaired sources differ deliberately. Replay against the wrong engine is not an integrity test. Source-exposed controls are not player reports, solver optima or enjoyment measurements. Partial reviewer harness development outputs remain labeled and included.
