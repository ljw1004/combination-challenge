## Hypothesis and fixed scope

A connected retained site introduces useful transformations early and gives earlier actual things later functions: a camera's player-made observations supply display/reference records, a temporary fitted filter becomes a protected returned record-bearing object while geometry copies keep services running, and a real mesh tool becomes a screened specimen/record archive. All public goals are available from the beginning; labels suggest purposes, not chapters that lock recipes or demand confirmations. All initial objects are blank: camera, rootbed, raw clay and mesh master. **No initial observation records or sample contacts exist.**

Prediction: fresh players identify specific earlier creations whose later changed use was worth doing, with useful or comfortable familiar enactment into the whole project's later purposes. Contrary result: later work is only another checklist, valuable experience ends with opening, or retained relations are merely prose covering independent rebuilds. A short unchanged prefab completion is valid and must stay visible. The complete finite endpoint is all sixteen current goals simultaneously true and the two lifecycle achievements earned; early voluntary stopping remains legitimate.

## Explicit semantics changes, not repairs to the old frozen game

### Active fitting is a functional interface

This candidate adds `Part.activeFit` and the publicly inspected place field `waterOutlet: 'fitted-porous'`. A successful actual fit seats a surface at that place. A copied design has geometry but no contact or events; moving the actual containing assembly clears its parts' active seating, while historical fit events remain. A shape-preserving transformation retains the seat only while its profile still matches. The outlet at filter-pad grants water to an object only through its own exposed open porous matching surface actively seated there. Hand water remains available for wetting clay before seating.

Thus the same porous soft form **without fitting** does not obtain outlet water or supply nursery growth; this is a causal action rather than an extra history requirement. Any matching porous mesh/material is eligible—no canonical recipe password. Lining a still-fitted surface closes that local water passage. Other ordinary source/interface laws remain unchanged. Redundant real filters are permitted; the fitted surface need not be the sole possible cause.

### Physical-copy record provenance

The old actual observation already stores immutable `viewLenses`. New physical copy events expose `sourceInitialKeys` from that snapshot as well as legacy singular source identity, so a player-produced observation made after an original camera joins a glass host remains attributable to its actual original lens. Adding an original later cannot rewrite earlier records. The selected readable carrier restriction still applies; blueprints clear events and cannot invent observations or physical-copy provenance.

### Prospective CLI friction condition

Only this new CLI changes the default output: goal changes/count summary and changed objects, not eighteen unchanged statuses on every combine. Every full goal/rule/part remains explicitly available. Default catalogue returns an exhaustive section index; `sections`/`chunk` provide lossless bounded public JSON display with hashes/next positions and exact captured delivered bytes. Capture evidence separately retains the full unpaged source. These interface and fitting/provenance changes are **additional confounds**, not proof shared-site continuity alone caused any later report.
