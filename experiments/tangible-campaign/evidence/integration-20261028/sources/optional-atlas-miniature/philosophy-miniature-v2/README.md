## Why these two pairs are defensible

The help desk already supplies a particular citizen’s unmet need, an insult, and a practice that distinguishes an event from the response to it. Within that practical context, considering the need without making wounded pride the judge does not logically require first considering Cynic independence. [Marcus, Meditations IV.3–4 and12](https://classics.mit.edu/Antoninus/meditations.4.four.html) supplies both judgment practice and orientation toward others/common benefit. This is a contextual practical application, not a deductive proof that two sentences exhaust ethics.

The physician and shepherd explicitly offer competing beneficiaries of skilled practice. Directly comparing them can preserve the owner-benefit explanation without first attaching each to the same ruler token. [Republic I,342–343](https://classics.mit.edu/Plato/republic.2.i.html) contains that dispute. The alternate output is deliberately the existing limited rival statement, not a new universal verdict about expertise.

The observed eclipse + moral-authority claim was **not** made an alternate recipe. Distinguishing the old prediction from a new observation before establishing a successful forecast is a substantive epistemic step; the blind reader found it defensible once clarified.
