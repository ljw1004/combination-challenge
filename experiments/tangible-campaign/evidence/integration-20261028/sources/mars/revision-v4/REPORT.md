This removes one unearned paper-processing action rather than replacing it with a renamed paper gate.

### Workshop: the shared bench becomes an actual fitted workstation

- The cached guarded machine is specified as the expedition’s **stored bench-top machine**, with its guard/controller/captive clamps intact.
- One installation fits it into an optional machine slot on the **earlier-created lit workbench**. The workbench is explicitly portable and has matching mounting rails; its lamp stays visibly attached.
- Only the fitted workstation has `guarded-machining`. Existing axle and bracket operations now use that same workstation and require the capability.
- The machine becomes a visible fitted slot, not a loose duplicate elsewhere. Neither the bench nor its lamp disappears. Both drag directions retain the bench’s identity and position.

Mounting a bench-top machine before running its stored programs is a physical setup with a visible result, not an inspection certificate or a token placed nearby. Both required Workshop goals depend on machining, so even the surviving old-crawler-alias branch must actually use the earlier bench. No runtime consumption rule or legitimate crawler repair/tow route was removed.

**Count is incidental:** one Night bookkeeping recipe removed; one Workshop installation added. Main route remains 200 combinations and the scenario 213 recipes across the same 24 chapters.
