## Evidence limits

- Simulated source-blind logical trials, authored smoke, source-aware counterfactual replay and human feedback are different evidence classes. This checkpoint's new trials are **not human trials**; source blindness is protocol-based, not independently proven isolation.
- Automatic advances and authored checkpoint setup are not fresh player combinations. Exact rejection, hint/highlight, stop and optional-exploration records are retained; completion does not prove comprehension, enjoyment or desire to return.
- Normal highlight exploration must not be reported as a concession or hint failure. Protocol and content both changed for some later trials, preventing causal improvement claims.
- Frozen UI files appear only where original manifests or replay dependencies require their exact bytes. Their presence is not evidence of new browser, native or touch testing.

## Reconstruct and verify

Large raw flat sessions are deterministically gzip-compressed; closed directory sessions are deterministic tar.gz archives. No source or event bytes are rewritten. To keep supported Git tree requests bounded, not-yet-stored archives and large text files use ordered `.preserved-base64/part-*.txt` UTF-8 transport; large text is losslessly gzip-compressed first. `storage-transport.json` records the original and encoded byte lengths/hashes and each part. The materializer validates and reconstructs these transparently. Existing verified Git objects are reused. `results/closed-logical-preservation-20261028/frozen-research-manifest.json` lists every original logical path, byte length, SHA-256 and Git blob hash, plus archive membership and exclusions.

From a repository checkout, restore into a **new** directory:

```sh
python results/closed-logical-preservation-20261028/materialize-evidence.py . /tmp/closed-logical-replay
```

The helper rejects overwrites/path escapes and verifies every restored file.
