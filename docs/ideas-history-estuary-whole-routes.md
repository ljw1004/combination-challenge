# Estuary candidate — whole-collection routes and missing causal rules

27 October 2026. **Paper-level construction routes, not executable traces, minimum proofs or play evidence.** Read with the named candidate and independent challenge. No source or deployed Mars changes. Each route reaches the same six declared projects; no isolated translation or fork fixture is proposed for recruitment.

## Settle a concrete behavioral core before claiming new ideas

The independent challenge correctly objects that mapping three event names onto three labels is too weak to carry experience translation. Use the following **proposed**, fully visible mathematical relations instead. They give the paper route actual consequences without claiming to model consciousness or an ecosystem.

### Processes and interfaces

`Beacon A` has angle knots `(time,angle) = (0,0),(1,45),(2,90),(3,45),(4,0)`, linearly interpolated. `Journey B` has knots `(0,0),(2,90),(3,30),(5,60)`. `Later C` is a distinct actual run with `(0,90),(1,30),(3,60),(4,0)`. Long Tide uses the same kind of trajectory over twenty time units, with an explicit rise, plateau and fall. All are authored fictional processes, not discovered natural laws.

An identity sensor receives `p=angle`. A pressure guide receives `p=angle/90`. A reversed instrument points at `angle=90-command`. Tracking succeeds when actual instrument angle equals the actual requested process angle throughout its piecewise-linear segments. A receiver enacts a score by producing its declared continuous output trajectory; the output is checked, not a completed-score flag. Whole runs occur automatically and their moments are not player selections.

A following practice maps input to output. For the pressure guide and reversed instrument the correct normalized command is `90-90p`. The relation transfers across all three public trajectories; it is not a lookup of their named IDs. A direct authored controller with the same function is equally valid. A fixed instrument can meet a stationary-view goal, but not a sweep that actually changes angle. A separately authored time schedule may match a particular fully known sweep and remains valid for that run.

A replay transformed by time factor `k` emits `p(k*t)`. A live interface emits the current `p(t)` after its mapping. They can be indistinguishable on a matching source, but differ on another actual trajectory. For example, the start of replay A is 0 while live C starts at 90. Historical source attribution is not the reason a replay fails C; its actual output is wrong there.

The tactile map `p=angle/90` is invertible on the declared range. The clipping map `p=min(angle/90,0.5)` is not: angles67.5 and90 both produce0.5. No method may recover which one occurred from that clipped value alone. A richer sensor, another informative channel, direct access to the original trajectory or abandoning that distinction are legal alternatives. This is an algebraic negative control, not a requirement to suffer a faulty interface in every project.

### Actors, learning and time

Mara initially can execute the basic identity following practice. Forking after an actual run creates local and travelling continuations sharing that lived prefix. The local continuation actually operates the reversed instrument; the traveller actually operates the pressure guide on Journey B. They retain different run histories. Their acquired practices may subsequently be taught in either direction. A known global recipe is not a fabricated actual actor episode, but a direct instruction can teach a practice without pretending its recipient travelled.

A willing receiver can learn a compatible practice from a public instruction or translated demonstration. Afterwards it must actually produce the relevant output on a later run. Learning is not certified merely by an episode ID or a newly named skill. Universal direct teaching is legal; the project's distinct-life requirement remains about what the people actually experienced, not what they are allowed to know.

The learner house uses the same declared practice interpreter, with a named sensor and actuator. This is a proposed new signal-control substrate, **not silently permitted by the current live-host move/hinge/connect-only executor**. It constructs no physical apparatus. A successor's later actual run produces new data; teaching that data to the former teacher is reciprocal learning of a subsequent occurrence, not a claim that the machine invented general science.

For the distant project only, a sent message arrives after the next whole local activity. School-role messages route to the holder at receipt; personal messages stay personal. The agreed festival is after receipt, so no unmodeled faster-than-light assent is needed. If instantaneous correspondence suffices for the chosen purpose, this delay should be removed rather than defended as extra gameplay.

## Complete-catalogue route C — the strongest reusable method is legal

Give the complete-catalogue condition an already constructed **Public Interface Adapter**: for any disclosed invertible sensor `f` and actuator `g`, command `g⁻¹(f⁻¹(input))`, plus an explicit time-rescaling/replay mode and live mode. It is one whole reusable method; known maps and valid literal programs are inexhaustible. It does not provide fabricated people, lived runs, installed apparatus or delivered messages.

A full short route is:

1. Mara enacts A and Long Tide; construct their actual episodes.
2. Adapter converts the real tide to a short tactile score; Ilen enacts it.
3. Fork Mara after that shared experienced prefix.
4. The local actually performs the reversed-interface activity; traveller actually performs Journey B through pressure. The adapter supplies both lawful mappings.
5. A whole Reunion Practice transfers their selected practices; each performs the other's kind of activity. Direct instruction may substitute for the transfer if the actual requested reunion relation is preserved.
6. Adapter renders the real expedition as Borrowed Horizon, then binds its mapping live to C for Ilen. A replay and a current response are both actually enacted, with different outputs where their inputs differ.
7. Construct/enact the linked performance with suitable participants; send it to the distant group.
8. Give the same adapter/bound practice to a willing successor and transfer the Local School role. Send the ordinary agreed event invitation before succession if checking role-addressed receipt is part of the chosen purpose.
9. The successor actually encounters the subsequent C occurrence; delivery advances. Teach that new sequence to the former teacher, who actually enacts it.
10. Remote recipients use the adapter for their interface; the agreed festival is enacted by current role holders, while separate local/personal projects continue.

This is ten **compressed milestones**, not ten selected actions. Some contain several binary constructions/enactments and must be expanded by a future engine's exact public action grammar. It is a complete causal route, not an action-count comparison. Do not compare “30 normal versus10 complete” as if the units matched. Their purpose is to expose the whole-catalogue saturation policy before any engine exists.

The adapter may be an excellent normal discovery. It may also make later construction routine. Neither finding alone answers whether learning the larger named ontology is worthwhile. A complete-knowledge end state is allowed to be capable rather than deliberately crippled.

## Alternative route D — direct authoring and ordinary cooperation

Give participants direct literal programs rather than deriving every method from episodes. Use independent willing instructors instead of a civic host where the project only needs a successor teacher. Use a shared ordinary schedule instead of a treaty. Use a plain visual performance for audiences whose purpose permits it, but supply an actual compatible output for Ilen's explicitly chosen tactile project. These substitutions can meet projects1,3,4,5 and6.

For project2, an unrelated pair of hired instructors is not a substitute for Mara's stated wish to continue two different lives from her experienced past. A lawful multi-body continuation with genuinely separate ongoing episodes may be a substitute if the semantics support it. The reason is the desired life, not an original-ID password or a named Fork Kinship receipt. Copies of a single archive do not generate two lived runs.

No direct-author route can recover a distinction from a clipped signal alone; however it can use the public original process or a richer sensor if that access exists. Do not forbid those alternatives merely to make the Sensory Loom mandatory. Likewise a fixed time schedule matching one public run is valid; only an actual different input exposes the difference from live following.

## Reuse audit: what changes role rather than merely persists

- **Following relation:** observation controller → traveller skill → translated live interface → successor operation. Same function, different actual bindings and participants.
- **Angle/pressure map:** expedition sensing → replayed artistic experience → control of a current instrument → distant interface adaptation. Its invertibility has a real consequence.
- **Actual source episode:** a lived event → shareable replay → taught practice/input to a performance. Its later use does not rewrite who lived it.
- **Reunion:** shared ancestry becomes reciprocal usable competence while actual later histories remain distinct. It does not add permission to ordinary service.
- **School role:** original holder → successor serving an actual later input → former teacher learning from successor. This is a changed relationship, not only a handover flag.
- **Shared score:** local performance → transported knowledge → remote enacted event. Delivery matters only because the new score was not already known there.

The route fails its intellectual ambition if these consequences reduce to correct labels or if interface algebra makes every person/place interchangeable. A signal-programming toy could still be worthwhile, but it should not be sold as a world of ideas on the strength of names alone.

## Missing rules and implementation gate

Before coding a whole candidate, settle these precisely:

1. **Representation and equality:** exact rational knots, interpolation, simultaneity, time rescaling and trajectory comparison. Numeric tolerance must not become a hidden answer band.
2. **Program grammar:** finite permitted following/interval/translation operations, composition order and public examples. Whole universal adapters and direct literal programs must have explicit legal semantics.
3. **Control causality:** whether sensing and actuation are instantaneous, delayed or sampled. The paper route assumes instantaneous piecewise-linear functions; do not claim real control-system stability.
4. **Binding and portability:** map/reference inputs versus actual instruments/people; how a named portable practice binds somewhere new without copying its source's lived history. No sticky generic assembly bag.
5. **Learning:** precisely what instruction or demonstration transfers, and how a later run proves actual changed repertoire. Do not require extra demonstration paperwork for already known capable actors.
6. **Fork/merge/consent:** explicit continuations, independent choices and valid alternatives; no philosophical definition silently promoted to scientific fact.
7. **New experience:** what creates the successor's new actual input, and which later observable practice it can teach. A copied episode ID cannot satisfy reciprocity.
8. **Event scheduling:** one public rule for whole activities, delivery and agreed events; no convenience chronology that changes after a shortcut is found.
9. **Action grammar and accounting:** expand both routes into the same binary public selection units before reporting any length. Keep automatic event moments separate.
10. **Content and interface:** named result previews must show trajectories and actual effects clearly enough to manipulate ideas, not compel raw algebra/JSON inspection. Presentation alone must not fabricate an unimplemented consequence.

Then construct complete normal, complete, direct-author and saturation witnesses for **all six projects**, mechanically challenge them, freeze exact source/rules/assignment and publish before one fresh full-collection diagnostic. A small complete result remains a possible success; no new run is authorized by this paper. A roughly200-decision aspiration needs genuinely broader useful construction and actual full play, not more compulsory ancestors or extrapolating thirty rows.
