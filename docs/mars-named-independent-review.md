# Independent review — named, portable Mars

27 October 2026, approximately 00:35 UTC. This reviews the new named-binary game, **not** the earlier Working Materials physical assembly campaign. Its older review/results remain historical and are not evidence for this ruleset.

## Contract audited

The current content has 42 named things, 26 binary recipes, five stages, nine objectives and 15 prepared checkpoints. The ordinary witness contains 19 combinations and nine placements, plus stage changes. These counts are authored coverage, not a fun, duration or difficulty finding.

- One global thing per kind; no generic compound bags, actual/design split, copy action or cumulative place assembly.
- A and B remain after synthesis; dragged/first-selected A becomes loose near the target, B remains unchanged, and C is a new portable thing.
- Context is derived from **target B's actual revealed placement**, not a remote chosen location. A supplied `at` assertion cannot override it.
- Item+location can create a portable named output. When no novel location recipe is available, a gesture can instead make an ordinary reversible placement. A restrained placement cue is distinct from novelty highlighting.
- Slots hold one item. Replacement returns the prior occupant loose without merging or deleting it. Moving an item away immediately changes current goal truth; historical achievement/unlock is separate.
- Objectives introduce only their supplies and required locations. Previously encountered locations retain stable coordinates; existing tokens remain available without cloning.

## Findings corrected during review

- Draft location coordinates overlapped across stages; content now uses globally unique stable points.
- The draft witness relied on remote context/sticky source placement. It now uses ordinary watered-tray creation followed by the warm-habitat location operand, and actually places sealant at the repair bench before catalytic patch creation.
- The original crowded allocator stacked multiple unrelated things at the same fixed coordinate. The revised allocator reserves a nearby card-sized gap and can move only obstructing loose neighbours, preserving target B and placed items. The witness and optional-output regression pass.
- Placed things previously had different size/font/shadow styling. Placement now changes position only.
- Obsolete copy-related rejection text was removed. No copy controls or third object category are present.

## Effective-canvas fallback and resolved bounds findings

The earlier320×480 CSS-minimum mismatch is resolved by the root-approved readable fallback: the logical board is at least760×620, narrow/short windows scroll it with an explicit hint, and thing dimensions use board container units (at most10×6 normalized units). Locations use at most18×14 units. Desktop-sized viewports remain fitting rather than unnecessarily scrolling. Source/controller checks pass for initial centering, scroll preservation and a nearest `scrollIntoView` request for a created thing. These are not native scroll or text-fit tests.

The stronger final rectangle test exposed a second case: a newly revealed warm-habitat could intersect the existing loose cable. The correction relocates only loose things intersecting a newly revealed location's clearance area; placed and nonintersecting items retain their positions. The independent test permits this narrow, local position-only exception while preserving identity and forbidding unnecessary relocation.
