- Tempo/channel methods transform exact rational trajectories, preserving actual source links. Dual-channel score construction is explicit; the ensemble performs it through distinct compatible bodies. Angular controller commands are separate from pressure performance outputs.
- The successor encounters genuinely different D after succession. A lesson compares decoded trajectories including timing against the former teacher's repertoire **at teaching**, not score IDs or names. - Activity advances, then delivery/adoption, then actual performance; rejected actions roll back the entire selection. Same-activity festival delivery is legal. Personal destinations remain personal; school messages resolve the current holder on arrival.
- Distant participation requires the actual locally shared score, not an unrelated solo replay. A later actual personal B output demonstrates continuing local practice, by stored replay or retained following. The former teacher's independent D recall can also satisfy continuing personal life.

## Independent prefreeze challenge and fixes

Independent audit found failures not exposed by the initial successful routes:

1. A distant actor's already retained controller could not execute because its newly generated run score incorrectly underwent the remote instruction gate.
2. A generated run score could overwrite an authored score with a colliding ID.
3. Direct application of a new distant score rejected instead of queueing instruction.
4. The distant endpoint accepted a solo Tide instead of the locally shared score, rejected valid personal transmission and used the baseline score ID as a password.
5. Public CLI initially lacked exact hypothetical preview and complete exposed causal-history records; finish was not terminal and init omitted printed state from capture.

All were repaired before freeze. Original failing reproductions remain in `results/ideas-history-estuary-development/prefreeze-failures.txt`; independent regression tests preserve the counterexamples. This was an implementation review, not a fresh playtest. The independent review document owns its final assessment.

## Additions to the earlier executable specification

The v1 specification remains preserved. The implementation makes these previously implicit details explicit:

- `run`/`perform` combine local instruction and enactment; `follow`/`recall` specifically invoke retained capability. The distinction makes changed actor behavior testable without banning direct instructions.
- New remote `perform` queues personal score instruction without a world tick; it does not invent delivery or output. If that instruction is already pending, a later `perform` can itself advance delivery and enact it. Arbitrary new remote-controller transmission is not implemented.
- Role-addressed and personal score messages are both legal. Festival uses two matching role invitations; ordinary personal score transmission is enough for the distant project.
- Actual distant baseline-equivalent continuation must occur after its shared-score enactment, not only after receipt. It need not use a particular stored ID.
- Replay novelty ignores source/name IDs and mathematically redundant knots. Rendering retains declared channels, but equivalent decoded replay counts as already known even when presented through another channel.
- Two simultaneous bodies are modeled, not multi-body single persons. The guide explicitly states this finite embodiment limit.
- Public `preview` returns exact hypothetical state, automatic events and errors without changing accepted selections or state. All session command output is captured; finish prohibits further actions. Queries remain legal after finish.

## Remaining limits

This remains an exact-signal and relationship toy with authored processes and willing actors. It does not establish that the fictional conceptual vocabulary is itself rewarding, that reciprocal learning feels more than repertory management, or that there is enough worthwhile construction for a long campaign. Names cannot supply those missing results. All unimplemented laws are listed in the public guide. No browser or historical-realism claims follow from these tests.
