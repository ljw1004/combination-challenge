## Explicit supersession

| Historical direction | Current rule |
|---|---|
| Existing runtime/schema, old direct URLs and save migrations remain supported | Legacy is reference-only. The new Markdown applications have no compatibility obligation. |
| Persistent locations alone may trigger carry; same-place chapters cannot tidy | The spec's chapter surfaces, inherited images/hotspots and needs-based carry govern. |
| Placement truth can revoke goal completion | Achievements latch. Moving a witness never revokes an achieved goal. |
| Every transformation must preserve and display old internal parts | Slot installation preserves parts; transformation into a new identity wraps old details. |
| All recipes and output previews exposed to ordinary players | Compatible existing partners are visible; future result names remain developer information. |
| UI work frozen pending logical research | Browser/game development and real interaction checks are authorized. |
| Narrative must be exclusively emergent with little authored prose | Authored chapter popups and item wonders are explicit parts of the current format. Useful continuity through actions still matters. |
| Every action needs a consequential tradeoff; short solutions undermine fun | Learning, comfortable execution and valued closure can be enjoyable. Keep legitimate shortcuts. |
| No consumption anywhere / retain all optional recipes | Use declared fates and future-progress protection; cut purposeless optional branches. |
| Long-game length inferred from recipe totals or added setup | Measure actual play; do not pin arbitrary counts or inflate decisions. |
| Prior live checkpoint, release test counts or “current” headers describe the active product | Those statements retain their original date/version only. |
| Copy Workroom / all old sketches should remain selectable | Only the five current Markdown manuscripts are active. Other sketches remain reference. |

Retained principles are design intentions, not automatic assertions about every current story. An unresolved warning or old authenticity finding stays review work until it is checked against the active manuscript and resulting behavior.
