## Research question — not player onboarding

After the completed V1 sequence and the V2 slow-alternation tests, this is another **bounded explicit goal in the same 24-concept ontology**, not a new physics system or a campaign of authored scenes. The new question is whether intermittent inputs make retaining and transmitting a signal worth composing differently from direct source routing.

V1's publication construction separated exact original records from current public fragments. V3 retains that distinction but asks for the combined public signal **throughout an exact physical cycle**, including phases when each original source is off. The player receives all 24 known designs. It is not necessary to reacquire a branch or use every available concept.

No Beacon/Archive/Loop label is required by the goal. A genuine circulating construction is accepted if the existing laws support it. The author tests below deliberately preserve that alternative rather than changing physics to force a preferred recipe.

## Same map, same engine, disclosed different inputs

The wrapper uses the unchanged V1 publication map and causal engine. Starting conditions differ only as declared:

- A2 emits according to **[2, 2, 0, 0]**.
- E2 emits according to **[0, 0, 2, 2]**.
- Index the next emission by current tick modulo four.
- All 24 concepts are known; no route work/controller has been preconstructed.
- Fields begin empty at tick zero, rather than retaining stale water from the old constant-input initializer.

Each source is independently off for two beats. This prospective asynchronous schedule was chosen before player tests. It permits a real circulating-signal alternative under the existing one-edge propagation law. A one-pulse schedule was considered but not used; this is a declared board-input choice, not a retroactive physics patch.

The direct combined stream can still contain *some* water continuously, because the sources alternate. The challenge is continuous delivery of **both identities together**, not merely keeping the square wet. Do not report the negative witness as a complete water outage.

All material, recording, rooted transformation, broadcasting, valve, loop and packet propagation laws remain those of [Living Works 1](logical-living-works.md). Closed connected routes can retain circulating packets; beacons can continuously republish their own retained record. Those are already public engine behaviors, not new supplies or an inventory system.

## Public goal and temporal scope

Over **every phase of the entire established exact repeating physical cycle**:

1. B1 retains exact A only, and D1 retains exact B only.
2. C2 receives water carrying both A+B fragments and **no exact identity**, continuously.
3. An unflooded walking path connects A2 and E2.

Initial construction transients are not an all-history failure. A world edit clears the old cycle proof. There is no requirement that every cell in the world be dry; only the stated walking relationship is checked.

Physical equality includes all fields, resolved outlets, stored records, roots, controllers, material states and source phases. The wrapper records every actual beat inside a batched wait, not merely its favorable final frame. Up to 256 previous physical states are retained to detect a repeat; a longer unseen period is unverified rather than presumed successful.

Any legal architecture satisfying the outcome is accepted. There is no required component, action quota, deadline, depletion, repair demand or new ontology gate. `finish` is always valid; this single board has no `next`.

## Executed positive and negative witnesses

These are authored, privileged mechanical checks—not played-agent intentions or enjoyment findings.

All three witnesses first let the actual sources supply separate records, then construct the outgoing fragment relationships. Every final physical cycle has period four, including the asynchronous source phases.

| Architecture | Actual square delivery across the four phases | Originals / walking | Goal |
| --- | --- | --- | --- |
| Direct source → rooted route → square | B, B, A, A fragments, with water present | Both pass | **Fail:** not continuously combined |
| Stored original → outgoing broadcast → rooted route → square | A+B fragments in every phase | Both pass | **Pass** |
| Two-cell circulating routes with outgoing branches → square | A+B fragments in every phase | Both pass | **Pass; zero beacons** |

### Retained-record broadcast

B1/D1 receive and retain actual A/B. Their broadcast outputs are physically connected south toward B2/D2, which fragment them before forwarding inward. The stored records continue emitting when their original source is off. Merely possessing the Beacon concept or retaining a disconnected record would not provide the required delivery.

### Actual circulating storage

B1/D1 are ordinary archives, not beacons. Each is connected back to its rooted incoming neighbor. B2/D2 branch both back into that small circuit and inward toward the square. Consecutive source pulses populate the actual round trip; circulating fragments persist between future input pulses. The two independent streams reach C2 together in every phase while the exact archives remain separate.

This is accepted **without any Beacon or named Loop work**. The actual cell connections, fields and ongoing propagation carry the storage. Cutting B2's return branch breaks continuous combined delivery while leaving B1's exact original intact. The resulting counterexample distinguishes a functioning circulation from a label or retained-record badge.

### Full-cycle rather than endpoint success

Another regression removes one broadcast from the positive arrangement. Some later phases still show A+B at C2, while others lack A. Even when the current endpoint looks correct, the complete cycle fails. This tests the declared continuity requirement instead of awarding success for one favorable sample.
