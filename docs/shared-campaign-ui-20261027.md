# Shared declarative prototype playground

The seven new short scenarios use the same TypeScript rules engine in browser and logical trials. Things, binary recipes, contextual locations, goals, narrative travel/caches and named component slots are declarative data. The current format deliberately does not add object-to-location conversion, destroyed/closed earlier areas, or immovable-item special cases.

Current-scene packing recollects existing known needed things from visited areas as part of the narrated journey. Identities are preserved and engine transfer events record provenance; unneeded finished work remains physically on the continuous board. No supplies are cloned or silently granted. New primitive supplies require an authored story cache.

The browser adds presentation only: narrow600px worktable, physical retained areas, drag/click actions, partner-only hints, explanatory item text on hover/selection, exact current-objective gold, adjacent animated births, modal invitations, undo, reset and legal replay checkpoints. Components use the same internal slot rules as logical players.

## Seven deliberately small experiments

Food (25recipes), theology (12), restoration (14), shoreline (12), causation (14), literature (12), Chinese thought (11). Food and religion/theology were selected first; the others provide contrasting tests and may be discarded. No miniature is represented as a full200–300combination game.

Food's first source-blind logical player stopped after10discoveries because directional catalyst guidance was unclear and expected food combinations were missing. That v1 evidence remains unchanged. The current engine explains the receiving target and current Food adds fruit yogurt and bread-and-butter. Native browser checks verify the clarified action works; a fresh player improvement has not yet been established.

Independent authenticity review found no critical safety/history/universal-religion blocker. Literature and Chinese thought required actual content rather than empty named notes: the current versions contain an original poem and visible revisions, and sourced/paraphrased claims with a fictional disagreement case. These remain bounded authored abstractions, not historical causation or truth adjudication.
