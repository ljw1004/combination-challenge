## Risograph

Limited-palette screenprint / risograph aesthetic. This illustration by Alice Pattullo shows the kind of expressive, printed-object catalogue I have in mind. A few colours, deliberate imperfections, graphic shapes, decorative details. Modern, playful, but not the usual game-asset look. This could make the game feel like a beautifully illustrated children's nonfiction book, without looking childish. You can use colour to communicate different materials while retaining a consistent illustrated character.
