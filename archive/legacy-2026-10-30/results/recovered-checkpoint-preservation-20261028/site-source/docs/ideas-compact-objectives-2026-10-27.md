# Ideas: compact worktable and current-objective feedback

The worktable is centered and capped at 600 CSS pixels, matching Mars on desktop while remaining width-fitting on mobile. The model uses the same cap, so pointer movement and authored replays do not place tiles beyond the visible worktable. Existing discoveries remain tangible in earlier physical areas.

Gold now belongs only to the current invitation. Scientific method is gold in the inquiry stage only. A journal or encyclopedia becomes gold together with the Public library only after placement there during the library stage. The short tactile tide and Listening room become gold only after the correct tide is placed there during the final stage. Advancing clears prior-stage gold without deleting or moving the old witness. Moving a currently placed witness away clears its gold.

New creations use eight immediately adjacent positions around the target. A clear adjacent position wins; if crowded, the least-overlapping adjacent position wins. There is no search for a distant vacant slot. Creation never fails for lack of room, operands remain unchanged, and the new object is drawn above older tiles for its existing emergence animation.
