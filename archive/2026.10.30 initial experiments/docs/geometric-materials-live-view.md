# Pure current-view physical adapter

26 October 2026. New optional adapter for prospective build→teach→host integration, not an integrated play result. The published Geometric Materials engine and earlier campaign remain unchanged.

`faithfulViews(state, targets?)` returns actual current optical witnesses. The optional explicit scenario target array avoids changing exported map arrays or pretending that the frozen campaign contains new targets. Without it, the active frozen map's targets apply. New targets require unique IDs, finite coordinates and cardinal unit fronts.

The adapter intentionally mirrors the repaired engine's optical predicate: real lens heading, one-unit rear recording-plate position and normal, front-facing target, actual incoming and focal-path occlusion, selected lens/plate exclusions only. Results include object/lens/plate IDs, center/heading, subject position/front and all clear incoming/focal boundary witnesses. This is a pure query; it neither creates records nor clears novelty, transforms parts, applies actions, changes goals or spends an intervention. Returned mutable witness arrays do not alias the input world.

Record novelty is deliberately absent. A correct current view survives a duplicate-record rejection; an old stored record does not keep a blocked live view working. The controller must use ordinary `stepGeometricMaterials` actions and separately check continuing service. This query does not certify arbitrary fabricated invalid states: legitimate states come from the normal constructor and validated actions. It does not grant target completion or make explicit scenario targets into old-engine observation goals.

The pure predicate is duplicated rather than exported from a modified frozen engine. Differential tests bind it to engine SHA-256 `bfd42e457716596e0fb7cf42b453a49563ecd1daee91bdf31df1680eafe0144b`. A future physics version requires renewed differential review rather than silently assuming correspondence.

## Controls

Seven targeted tests cover exact witness equality to a fresh frozen-engine observation; duplicate observation versus current view; query/input and return-value isolation; explicit target fixtures without global mutation; actual direct half-turn operation on one camera; obstruction despite retained old records and lawful removal; static outward-facing cameras at different centers; malformed targets; opaque versus clear rear focal panels; and a cardinal placement/target differential sweep. Existing physical laws still allow replacement, copies, alternative apparatus and direct human control.

These are source-exposed mechanics controls, not player experience, an optimality claim or proof that a learner is necessary. A separate-front purpose allows the fixed different-center alternative. A common current viewpoint must be justified by the new requested experience, not a hidden rule introduced to defeat that alternative. The single relative half-turn may legitimately serve all opposed demands.

Full integration controls, source/assignment publication and a fresh neutral play are separate later gates. No previous campaign count or report transfers to the integration.
