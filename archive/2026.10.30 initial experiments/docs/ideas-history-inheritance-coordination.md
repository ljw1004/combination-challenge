# Unbuilt Inheritance: shared-ontology decision before implementation

26 October 2026. Design review only. No new game, source change, fresh pilot or scale result.

## Decision so far

Do not build a separate ecology engine merely to give the future-ideas branch another short puzzle. Coordinate any next scenario with the retained-material campaign. Its independently audited 76-combine project has specific, enacted appreciation of earlier creations changing jobs; the future-personhood pilot has six-combine constitutional configuration and a universal three-adoption repair. These are different evidence, not counts to add toward a campaign.

Ownership agreed in coordination: the ideas branch writes only `docs/ideas-history-inheritance*` design requirements at this stage. The material-campaign lead owns any prospective separate campaign core/content. Neither changes the existing retained project, delivered browser checkpoint, or frozen evidence. No implementation proceeds from this memo alone.

## What inheritance could add

The original speculative combination is **Reversible City + Trusteeship → Unbuilt Inheritance**: make a place useful now while leaving successors distinct useful transformations. This need not require irreversible catastrophe, difficult choices at every step, or a proof that some future becomes forever impossible. Comfortable modular construction and lawful recovery are welcome. But the evaluator must distinguish:

1. Two labels or permission flags.
2. Two physically different end configurations that can trivially be made anywhere.
3. A present creation whose actual retained structure helps enact different future purposes.
4. A deeper option-preservation problem in which choices alter reachable futures or materially different recovery paths.

A small result at level 3 may be worthwhile without level 4. No state field named `inheritanceProtected` should award it. Demonstrate both transformations from the same actual checkpoint using public laws. Report whether structures persist for a functional reason, a required identity condition, or a voluntary choice.

## Existing physical-law collapse

Source inspection of `experiments/logical-retained-project.ts` confirms that an entire hinged folded root has height and width one, irrespective of component count. Anchors have no occupancy exclusion. Copies preserve properties/geometry, not actual records or fits. The public model permits indefinite fresh copies and whole-route movement. These are existing disclosed abstractions, not defects to repair retroactively.

Consequently, a new goal asking only for present service and two alternative later services is likely solved by copying separate assemblies, co-locating them, and folding/moving a universal frame. Simply retaining the same named original would forbid replacement without demonstrating why anyone values that particular material. Adding two future-check badges would recreate the permission/provenance problem.

The material lead also reports an independently tested three-combine cart/hinge/camera utility supporting a complete 83-action ordinary route; the fresh retained-project player completed in 76. Those whole-project routes do not prove a particular unimplemented inheritance layout solvable, but strengthen the need to test generous copying/folding rather than assume spatial depth.

## Ecology sketch: useful rejected inference, not selected engine

See [the exact five-cell proposal](ideas-history-inheritance-world-proposal.md). It has actual rooted supports, roofs, shade, reed-built substrate, erosion and two distinct successors: canopy dwelling and sunny reed commons. A cut support really collapses shelter and can require reed restoration before tree establishment. These are world consequences, not authority settings.

The attractive initial story that a nursery roof helps neighboring trees establish does not survive the exact rules: the corrected canopy witness removes the roof early so all trees grow together. A safe bank refuge and lawful clear/replant/rebuild sequence preserve eventual reachability of both futures. Keep this result rather than banning retreat or manufacturing a finite sediment inventory.

That universal recovery does not falsify all possible enjoyment or comfortable construction. It **does** defeat a strong claim that this specification creates deep preserved-options choice. Several new ecological laws would be needed to test a modest changing-world hypothesis which the played material track already partly supports. They are presently unearned complexity.

## Smallest candidate worth considering jointly

One place with genuinely different uses, such as a sheltered working court and a sunlit growing court, could reuse material boundaries, light, supports and water. A present installation should have useful work to do; successors should change those actual services. A common scaffold may legitimately be the best answer.

A proposed spatial law is warranted only if a concrete function requires it: an occupied structure physically obstructs another structure or sightline; a panel has real extent while folding; a contact must meet a surface. Finite space is not forbidden inventory economics. But introducing occupancy, shape or obstruction solely to defeat a known shortcut is not justification. The same law must apply consistently to new copies, original parts and alternative materials, and should serve other campaign purposes too.

Before adding any such law, the campaign lead should supply two actual configuration witnesses and the proposed present service, then run these controls:

- Build/copy separate universal service assemblies at every permitted location.
- Fold/open/re-aim the same rich scaffold for each future.
- Relocate the present service to any lawful spare site and rebuild the target site.
- Replace original components freely where their actual retained function does not require them.
- Complete both future services simultaneously if the world permits it.

If these solve the goals pleasantly, preserve the short answer. If they render the new purpose indistinguishable from existing station construction, do not implement inheritance merely as another name.

## Prospective test and stopping criterion

No player recruitment yet. First agree a shared-world purpose and minimal law delta; then implement in separately named campaign files, test deterministic transitions and alternative witnesses, independently challenge universal policies, freeze source/public assignment/protocol, and obtain verified publication before one fresh pilot.

The falsifier is not an action minimum. It is that the player enacts interchangeable service setups or clerical option certificates, with no useful role change attributable to the retained creation. Positive evidence would name and mechanically substantiate a retained structure making later purposes intelligible or satisfying, including comfortable obvious reuse. A report of appreciating future-world imagery is separately valuable but does not establish mechanical depth.

If no independently justified law/purpose emerges from coordination, retain these documents as an unselected design result and pursue the material campaign's stronger existing purposes. No requirement exists to turn every speculative ontology node into a separate engine.
