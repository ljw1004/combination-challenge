# Estuary binary player wrapper — separate freeze

27 October 2026. This package adds a restricted logical player command surface and neutral whole-collection assignment **without changing the verified substrate or binary adapter**. It is not a player session, physical UI, fun result or publication claim. Root alone verifies publication and authorizes recruitment.

## Player surface

`experiments/ideas-history-estuary-binary-player.ts` provides current state/objectives, existing-piece inspection, compatible existing-partner hints, actual two-piece combination, finish and help. Future names/trajectories are not returned by hints. After commitment, actual created outputs are visible. Developer preview, source, routes, arbitrary JSON engine actions, wait and extra configuration arguments are rejected and captured. No authored route is imported.

The exact assignment is saved in `ideas-history-estuary-binary-player-assignment.txt` and captured verbatim at initialization. It permits any order, shortcuts, partial completion and early stopping; asks for honest assessment rather than praise; supplies no action target or route. The protocol documents both setup and exposure boundaries. The existing source-exposed 18/20/21/22-gesture witnesses remain separate from future player evidence.

## Persistence and evidence

Initialization captures exact assignment, initial output, all objective descriptions, coordinator-supplied publication revision and hashes of executing sources. Subsequent queries, accepted/rejected actions, exact arguments/optional notes, outputs and automatic transitions are recorded separately. Gestures, causal commands and deliveries retain separate counts. Finish closes mutations while allowing recorded read-only queries.

Full-session deterministic replay validates not only the world but assignment, output history, rejections and finish state before every resume; executing-source drift refuses continuation. The independent reviewer identified that world-only replay would not catch edited finish flags/capture outputs; the wrapper was repaired before final tests. These were code-review findings, not claimed captured failing executions. Atomic replacement under exclusive lock prevents ordinary partial writes/concurrent writers. Deliberately reconstructing an entirely coherent forged journal is outside this non-authenticated local evidence model.

This command surface is **not an OS sandbox**. The coordinator must mediate player access and withhold source, developer APIs, authored routes and the internal audit file. If a run exposes them, label it accurately; it is not unrevealed-result discovery play. Stale lock recovery requires coordinator investigation.
