# Creation: Ravilious style experiment

Requested 6 November 2026 as one alternative to the preferred mosaic. The experiment keeps the mosaic's composition and translates its medium into the watercolour, shaped planes and directional pencil/dry-brush treatment of Creation's backgrounds. It is a comparison deliverable, not an adopted replacement for the live [icon](../../../../stories/creation/icon.png).

**Concluded 6 November 2026:** after comparing the variants, the user chose the original mosaic. Their reason was that mosaic, with its glass and glazes, welcomes saturated colours. The mosaic remains the selected catalogue identity; these requested comparison artworks are retained as completed experiment deliverables.

The built-in image-generation tool first used the [mosaic master](../../../2026.11.06%20story%20icons/masters/creation.png) as the edit target, with four style references: the supplied Ravilious landscape, the supplied Pillars and four-scene studies, and the current river-coast background. The user then requested the mosaic's intensity and saturation with the new watercolour medium, found that result too saturated, and asked for a halfway treatment between the muted and vivid paintings. The final request preserves the painted shapes and textures, with moderate mineral blues, natural greens, honey/ochre light and gentler tonal contrast.

[first-request.json](first-request.json) records the initial style transfer. [saturation-request.json](saturation-request.json) records the vivid colour revision. [muted-master.png](muted-master.png) and [saturated-master.png](saturated-master.png) are retained as the two necessary inputs for the midpoint request in [request.json](request.json). All requests preserve exact prompt text and repository-relative input paths. [master.png](master.png) is the revised output; [icon-256.png](icon-256.png) is its transparent 256px comparison export. Run `node export.mjs` here to repeat that reduction on macOS.

The supplied [inspiration collection](../../inspiration/README.md) contains all eleven original files, checked against `9bce83cd4d035d8a58ef458cb2b6cdbdd441a845:projects/creation-study/inspiration`. This comparison and its references were consolidated into the same Creation study on 6 November. The requests preserve their original input paths: files formerly under `archive/2026.11.06 story icons/creation-ravilious-experiment/` are now beside this README, and those formerly under `archive/2026.11.05 creation revision/inspiration/` are in the linked collection. The shared mosaic master remains at its original location.

Visual review confirmed the retained light/wave/tree/bird/fish composition and the intermediate colour treatment. The comparison export is 256 × 256 with alpha. At the original verification, all recorded input paths resolved; their current locations are mapped above. The live mosaic icon remains byte-identical. No application code or gameplay changed, so application tests and a build were not needed.
