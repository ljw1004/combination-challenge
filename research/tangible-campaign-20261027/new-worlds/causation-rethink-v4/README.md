# Why This Boat? Purpose-driven revision

A two-scene, eleven-combination prototype using the existing declarative grammar. The miller's loaded cart determines a broad ferry; a stranded fisher beyond a narrow reed gap determines a slim skiff. The same timber and tools serve contrasting ends, which precede measurement and construction. Formal arrangement, material and skilled making are visible, but none alone explains why this particular boat was built.

Final goals are exact capable-boat placements. Launching the ferry at Creek landing represents the compressed cart crossing; launching the skiff at Reed mouth represents the rescue. The suitable boat and its place turn gold. There are no Cart across/Fisher safe outcome tokens in the playspace. Wrong-boat placement fails the capability requirement, without pretending to simulate grounding or hydrodynamics.

This is an invented illustration of artifact purposes, not a claim that nature plans like a human or a historical reconstruction of Aristotle's examples. The primary source is Physics II.3 and II.8–9. The builder is the implied agent; tools alone are not claimed to be the complete efficient cause. A useful counterfactual: if the fisher leaves before launch, what was the skiff built for? Successful use and intended end are not identical.

Reproduce: python build.py; node validate.ts. Validation covers all eleven combinations, two legal checkpoints, five scene-two packed things, exact placement goals, and an actual retrieved broad ferry failing the narrow rescue goal. Maximum ten local things in the authored route. This is source-aware correctness evidence, not fresh-player enjoyment or physical UI evidence.
