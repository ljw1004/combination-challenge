# Earlier creations must do useful work

The new witness audit follows accepted actions to each chapter's satisfied goals. It distinguishes prior creations used in any combination from prior creations that actually feed a goal, including through current-chapter intermediates. It also recognizes placing a previously created thing to satisfy a current placement goal. An unrelated optional combination cannot launder a disconnected chapter; carrying a thing alone does not pass. Initial raw supplies are not creations.

This is an audit of supplied routes, NOT a theorem over all possible routes and NOT a certification that the narrative connection is meaningful. Run alternate legitimate producer routes as separate witnesses and challenge historical/narrative connections independently. Rejected actions throw. All examined completed chapters are reported; unfinished traces do not certify later chapters.

Four focused tests cover disconnected raw inputs, unrelated optional use, intermediate ancestry, genuine placement reuse and rejected actions. Baseline replay of all six focus journeys confirms four Mars gaps and twelve Atlas gaps. Elements, Food, current Boat and current Doctrine pass this mechanical requirement; that does not establish adequate depth or fun.
